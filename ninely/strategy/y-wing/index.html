Y-Wing in Sudoku: How the Three-Cell Bent Triple Works

By Avi Israeli · Worked boards verified by Ninely solver check · Updated November 2026

What is a Y-Wing?

A Y-Wing (also called an XY-Wing) uses three cells that each hold exactly two candidates, linked in a chain. Call the digits A, B and C:

  1. The pivot holds {A, B}.
  2. One pincer holds {A, C} and sees the pivot (same row, column or box).
  3. The other pincer holds {B, C} and also sees the pivot.
  4. The two pincers do not see each other. If they did, the three cells would simply be a Naked Triple.

Whatever the pivot turns out to be, one of the pincers is forced to be C. If the pivot is A, the first pincer cannot be A and so becomes C. If the pivot is B, the second pincer becomes C. Either way, a C lands in one of the two pincers. So any cell that sees both pincers can never be C.

Worked Example: Y-Wing at R5C3 Removes 3 from Cell R2C1

The three wing cells on the board below (from the given digits only, with no earlier eliminations):

  • The pivot, R5C3: {2, 6} (A = 2, B = 6).
  • Pincer 1, R3C3: {2, 3}. It shares Column 3 with the pivot, and holds the 2 plus the shared digit C = 3.
  • Pincer 2, R6C1: {3, 6}. It shares Box 4 with the pivot, and holds the 6 plus the same C = 3.
  • The pincers do not see each other: R3C3 and R6C1 are in different rows, columns and boxes.
  • The logic: If R5C3 is 2, then R3C3 cannot be 2, so it is 3. If R5C3 is 6, then R6C1 cannot be 6, so it is 3. Either way a 3 sits in R3C3 or R6C1.
  • Target R2C1: It holds {3, 7} and sees R3C3 (same box) and R6C1 (same column). Because one of those two cells is a 3, R2C1 cannot be 3. That leaves 7 as a Naked Single.

⚠️ The Tempting Wrong Move: Placing 3 in R2C1

R2C1 has just two candidates, {3, 7}, so a quick guess of 3 looks harmless.

Why this fails: A 3 in R2C1 removes the 3 from R3C3 (same box) and from R6C1 (same column). R3C3 is then forced to be 2 and R6C1 to be 6. The pivot R5C3 sees both of them, so it can be neither a 2 nor a 6, and it has no legal digit. That is a contradiction, so R2C1 is not a 3.

💡 Solving Tip: Start From Two-Candidate Cells

List the cells that have exactly two candidates. Pick one as a possible pivot, find two of its peers that share one digit each with it and a third digit with each other, and check that the pincers do not see each other. Only then look for cells that see both pincers and still hold the shared digit.

When to look for it

A Y-Wing is a good tool when the grid is full of two-candidate cells (bivalue cells) and the pair, triple and locked-candidate techniques have not moved the puzzle. It is a step above a Naked Pair in difficulty, because the cells do not sit in a single unit; they are connected by sight lines instead.

Pivot cells are the easiest to find, so start there. Scan a box or a line that has several bivalue cells, check the pivot's peers, and test whether any pair of them completes the A-C, B-C pattern.

Common mistakes

  • Using pincers that see each other. If the two pincers share a unit, the three cells are a Naked Triple, a different pattern with different eliminations.
  • Eliminating the wrong digit. Only the shared digit C is removed, from cells that see both pincers. The pivot's digits A and B are not touched.
  • Counting a cell that sees only one pincer. Seeing one pincer is not enough. The cell must see both.
  • Choosing a pivot with three candidates. All three wing cells hold exactly two candidates.

How it connects to other techniques

The reasoning is the same as in an X-Wing: you do not need to know which of two possibilities is true, because both lead to the same elimination. A Y-Wing replaces the rectangle of an X-Wing with a bent chain of three cells. If the chain collapses into a single unit, you are back to a Naked Triple. After the elimination, look for a Naked Single, as in this example.

Practice routine

Mark every two-candidate cell on a stalled puzzle. For each one, write the digits it shares with the other bivalue cells it can see. Look for a closed chain A-B, A-C, B-C, then list the cells that see both pincers. Repeat with a new pivot until you find one that removes a digit. Finding the pattern gets quicker after about ten puzzles.
