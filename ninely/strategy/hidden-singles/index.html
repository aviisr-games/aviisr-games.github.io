How to Spot Hidden Singles in Sudoku

By Avi Israeli · Reviewed by Ninely Engine Logic Council · Updated November 2026

What is a Hidden Single?

A Hidden Single occurs when a particular number can only fit in one remaining cell within a unit (a row, a column, or a 3×3 box), even though that cell might have multiple other candidate numbers written into it.

It is called "hidden" because if you inspect only the cell, you might see pencil notes like {2, 4, 7} and think the cell is unresolved. But if you look at the entire 3×3 box, you discover that 4 cannot be placed in any other cell of that box because crossing rows or columns block it elsewhere!

Worked Example: Placing 4 in Box 1

Observe the top-left 3×3 box (Box 1, Rows 1–3, Columns 1–3):

  • Row 1 has empty cells at Column 2 and 3. But Row 1 already intersects with a 4 in Column 8.
  • Row 2 has a 4 given in Column 6, so no cell in Row 2 can hold a 4.
  • Row 3 has only one empty cell remaining at Row 3, Column 3.

Because crossing 4s block all other empty positions in Box 1, Row 3, Column 3 is the only available shelter for 4!

⚠️ The Tempting Wrong Move: Placing 8 at R3C3

A player looking at the row might see that 8 is also missing and place 8 in R3C3 because "it isn't in Row 3 yet."

Why this fails: Placing 8 in R3C3 starves Box 1 of any valid location for 4! With R3C3 filled with 8, 4 has zero legal cells remaining in Box 1, creating an irrecoverable dead board. Always check whether placing an alternative digit makes another digit impossible to place in that unit.

💡 Solving Tip: Cross-Hatching Technique

The fastest way to spot Hidden Singles in 3×3 boxes is called cross-hatching: pick one digit (e.g. 1), trace its horizontal and vertical lines across neighbouring boxes, and see which box has only one unblocked cell left.
