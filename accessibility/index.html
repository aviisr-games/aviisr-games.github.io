Accessibility Statement

aviisr games (Avi Israeli Rozin, Israel) · Last updated: November 23, 2026

Commitment to Accessibility

aviisr games is committed to making aviisrgames.com and our mobile games accessible to people with disabilities. We aim to conform to Israeli Standard IS 5568 and the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA.

Accessibility Features on This Website

  • Semantic HTML landmarks (<main>, <nav>, <footer>) and structured heading hierarchies.
  • "Skip to content" links and visible keyboard focus indicators (:focus-visible).
  • Color contrast meeting WCAG 2.1 AA thresholds (at least 4.5:1 for normal text and 3:1 for large text and UI components).
  • Full right-to-left (RTL) layout support for Hebrew and Arabic using logical CSS properties.
  • Respect for operating-system reduced-motion preferences (prefers-reduced-motion: reduce).
  • Alternative text descriptions on meaningful images and screen-reader labels on repeated action links.

Exemption Notice (Regulation 35F)

As an independent one-person studio, aviisr games maintains turnover-based exemption documentation under Regulation 35F of Israel's Equal Rights for Persons with Disabilities (Service Accessibility Adjustments) Regulations, 5773-2013, while continuing to implement and improve WCAG 2.1 AA accessibility across our website and apps.

הצהרת נגישות

aviisr games (אבי ישראלי רוזין, ישראל) · עודכן לאחרונה: 23 בנובמבר 2026

מחויבות לנגישות

aviisr games מחויבת להנגשת האתר aviisrgames.com והמשחקים שלנו לאנשים עם מוגבלות. אנו שואפים לעמוד בדרישות תקן ישראלי ת״י 5568 ובהנחיות WCAG 2.1 ברמה AA.

התאמות הנגישות באתר

  • מבנה HTML סמנטי הכולל אזורי תוכן ראשיים (<main>), ניווט (<nav>), כותרות מדורגות וקישורי דילוג לתוכן.
  • תמיכה בניווט מקלדת עם סימון פוקוס ברור (:focus-visible).
  • ניגודיות צבעים העומדת בדרישות WCAG 2.1 AA.
  • תמיכה מלאה בכיווניות ימין-לשמאל (RTL) לעברית ולערבית.
  • כיבוד העדפת הפחתת תנועה במערכת ההפעלה (prefers-reduced-motion: reduce).
  • טקסט חלופי (alt) לתמונות ותיאורים נגישים לקוראי מסך.

הודעת פטור (תקנה 35ו)

כסטודיו עצמאי של אדם אחד, מפעיל הסטודיו מחזיק בתיעוד פטור מבוסס מחזור לפי תקנה 35ו לתקנות שוויון זכויות לאנשים עם מוגבלות (התאמות נגישות לשירות), התשע״ג-2013, תוך המשך השקעה ושיפור מתמיד של הנגישות באתר ובאפליקציות לפי תקן ת״י 5568 / WCAG 2.1 AA.
