# aviisr games logo

Files
- mark.svg: the ii mark alone, transparent, for dark backgrounds.
- mark-light.svg: same mark for light backgrounds.
- app-icon.svg: 512x512 navy rounded square with the mark.
- ../../favicon.svg: simplified for 16-32 px (no trail dots).

Colours
- Dark: navy #101426, cream #FFF4E4, coral #FF5A4F, mint #3DD6A3, muted #97A0BF.
- Light: coral #F0473C, mint #12B886, ink #101426, muted #6B7088.

Rules
- The name is always lower case: aviisr games.
- Never recolour or stretch the mark; keep the jump dot.
- Keep clear space of at least one stem width around it.

The wordmark is live text ("aviisr" weight 800, "games" smaller, muted) plus the drawn ii. An outlined wordmark file does not exist yet.
