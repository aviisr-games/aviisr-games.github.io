Aviisr Games logo files

Which file to use:
- ring.svg: site header.
- ring-on-dark.svg: avatars and favicons.
- lockup-dark.svg: share images and documents on dark backgrounds.
- lockup-light.svg: share images and documents on light backgrounds.

Colours:
- #FFB547 (amber, the ring)
- #15171C (ink, dark background and light-version text)
- #F5F2EA (paper, light background and dark-version text)

On light backgrounds the ring is ink (#15171C), because amber on paper is too faint.
Rules: use only these colour pairs; do not stretch, rotate, or add effects (shadows, gradients, outlines) to the mark.
Status: a candidate for the studio mark, pending the owner's logo decision.
